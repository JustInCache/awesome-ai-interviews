# Contributing

Thanks for helping make `awesome-ai-interviews` useful for real interview preparation.

## Content Standard

Strong contributions are:

- Interview-ready: concise enough to say out loud.
- Practical: include trade-offs, failure modes, and production details.
- Current: avoid undated claims about specific model versions.
- Navigable: link related questions, roles, and topics.
- Attributed: preserve source attribution when adapting existing content.

## Pull Request Checklist

Before opening a pull request:

- Run Markdown lint locally if possible.
- Check internal links.
- Keep one topic or role per pull request.
- Add sources or attribution for adapted material.
- Use the pull request template.

## Question Format

Use the canonical question template from `docs/REPO_ORGANIZATION_PLAN.md` until `docs/question-template.md` is added.
